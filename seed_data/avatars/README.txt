Аватарки КапперХаб — 30 штук (15 мужских, 15 женских), 128×128
================================================================

Папки
  svg/          исходники, 128×128, viewBox 0 0 128 128 — масштабируются без потерь
  png-128/      1× для интерфейса
  png-256/      2× для retina
  circle-128/   то же, но обрезано в круг (прозрачные углы) — если скругление
                нельзя сделать стилями

Имена: male-01 … male-15, female-01 … female-15

Как использовать
  В интерфейсе берите png-128 (или svg) и скругляйте стилями:
      .avatar { width: 40px; height: 40px; border-radius: 50%; object-fit: cover }
  Фон у каждой аватарки сплошной и заполняет весь квадрат, поэтому при любом
  радиусе скругления углов не видно. Файлы из circle-128/ нужны только там,
  где CSS недоступен (письма, пуши, превью в мессенджере).

Стиль
  Плоская векторная графика без градиентов, в одной системе с обложками видов
  спорта: сплошной цветной фон + лёгкий паттерн (полосы, точки, сетка, кольца),
  плоские формы, тёмная линия #141519 для черт лица.

Что меняется между аватарками
  фон        15 цветов из палитры сайта
  паттерн    диагональ, точки, сетка, полосы, тонкая диагональ, кольца
  тон кожи   6 градаций
  волосы     8 цветов × 9 мужских и 9 женских причёсок
  борода     щетина, полная, эспаньолка, усы
  аксессуары очки, кепка, наушники, серьги, повязка
  одежда     8 цветов, у части — цветной ворот
