Да, план на 7 мелких шагов:

1
Вернуть видимость рефералок в профиле
Проверить подключение front/static/front/js/profile-referrals.js в templates/cabinet/profile.html: сейчас вкладка “Рефералы” создаётся через JS, но скрипт, похоже, не подключён. Быстро восстановить отображение для капперов.

2
Сделать реферальный код общим для всех пользователей
Добавить реферальный код не в AnalystProfile, а на уровень User или отдельной модели UserReferralProfile. Старые коды капперов перенести миграцией из AnalystProfile.referral_code. Делай так чтобы был один источник правды и для капперов и для пользователей 

3
Переделать модель переходов
Вместо CapperReferralVisit сделать общую модель рефералов: referrer, visitor, session_key, visits_count, registered_at, subscribed_at. Капперы и обычные пользователи будут иметь одинаковые ссылки.

4
Обновить ссылки и endpoint статистики
/cabinet/referrals/stats/ должен работать для всех авторизованных пользователей, а не отдавать 403 обычным пользователям. В профиле всем показывать вкладку “Рефералы”, но блок “заработано” показывать только капперам.

5
Сделать начисления только капперам
Добавить сервис реферальных начислений: если пригласивший пользователь не каппер, только фиксируем статистику; если каппер, начисляем на real_balance. Начисления писать отдельными типами транзакций в RealBalanceTransaction. учти надо зачислять только за определенные действия пользователя например если тот купил у кого то подписку или же выиграл турнир или же (каппер)пополнил баланс

6
Вынести проценты в админку
В back.models.WebsiteSettings добавить настройки:
referral_tournament_percent,
referral_balance_topup_percent,
а также комиссии площадки для тарифов:
platform_fee_1_day_percent,
platform_fee_7_days_percent,
platform_fee_30_days_percent,
platform_fee_90_days_percent,
platform_fee_180_days_percent.
Добавить их в WebsiteSettingsAdmin на странице /admin/back/websitesettings/.

7
Подключить расчёты и покрыть тестами
В местах оплаты подписок, пополнения баланса и турнирных выплат применить настройки из WebsiteSettings.load(). Написать тесты: рефссылка есть у обычного пользователя, статистика доступна всем, обычный пользователь не получает деньги, каппер получает реферальные начисления, комиссия тарифа корректно вычитается по срокам 1/7/30/90/180 дней.
